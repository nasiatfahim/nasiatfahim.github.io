Personal

Full-stack AI

Multimodal AI search and recommendation engine

Problem
Enable shoppers to search an e-commerce catalogue using text, an image, or both while keeping results aligned with the changing product database.
My Role
I built the FastAPI retrieval service and the PostgreSQL-to-vector synchronisation pipeline, with Redis caching and containerised deployment.
Approach
OpenAI vision capabilities interpret image queries, ChromaDB supports hybrid text/image retrieval, PostgreSQL stores catalogue data, and Redis caches repeated requests.
Technologies
FastAPI, OpenAI Vision, ChromaDB, PostgreSQL, Redis, Docker.
Result
A working full-stack search and recommendation system with synchronised relational and vector data.

Personal

Computer vision

COWTRAIN: cattle weight estimation from photographs

Problem
Estimate cattle weight from an ordinary photograph when a livestock scale is unavailable.
My Role
I developed the end-to-end computer-vision and regression pipeline and served it through a FastAPI backend.
Approach
YOLOv8 instance segmentation isolates the animal and a reference object; the reference provides image scale, and regression maps extracted morphometry to predicted weight.
Technologies
YOLOv8, instance segmentation, regression, FastAPI.
Result
A working image-to-weight prediction pipeline designed for photographs from an uncalibrated camera.
